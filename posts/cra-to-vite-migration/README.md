# CRA → Vite Migration

Companion sandbox for the blog post **"Create React App is dead in 2026 — a weekend migration guide to Vite"**.

Run it to see a side-by-side map of every CRA assumption and its Vite equivalent — env vars, config files, SVG imports, absolute aliases, and the gotchas that trip people up.

```bash
npm install
npm start
```
